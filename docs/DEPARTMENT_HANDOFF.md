# 部署別引き継ぎ

1. `docs\TEAM_OPERATIONS.md`

## 依頼の受け方

ユーザーの依頼は、秘書が以下のどれかに分類する。

- 企画・編成
- リサーチ・条件確認
- 実測レビュー
- SEO・記事編集
- アフィリエイト管理
- デザイン・UI
- 公開・Search Console
- セキュリティ・法務
- QA・検収
- 集客・Growth
- アナリティクス・改善
- システム・安全管理

分類後、必要なら `docs\TICKET_BOARD.md` にチケットを追加する。

## 作業開始チェック

```powershell
git status --short
```

未コミット差分がある場合:

- まず差分を確認する
- 意図が分からない差分は戻さない
- 公開事故になりそうな差分はP0として秘書へ渡す
