# Skill運用

2本目以降の記事作成・更新は、過去の長いやり取りを再説明せず、次のローカルCodex skillを使う。

```text
C:\Users\kodai\.codex\skills\creator-stack-articles
```

## 使う場面

- 2本目以降の記事を作る
- 既存記事を更新する
- 実測レビューを本文へ反映する
- Search Consoleやsitemap確認から記事改善へつなげる
- 部署制とチケット管理を前提に、短い引き継ぎで続ける

## 指示例

```text
creator-stack-articles skillを使って、docs/TICKET_BOARD.mdのP0から進めて
```

または:

```text
Creator Stack Guideの記事2本目以降を簡略運用で進めて
```

## 注意

作業前に必ず `git status --short` を確認する。
未コミット差分に `example.com` や文字化けが見えている場合は、記事追加より先に差分確認を優先する。
