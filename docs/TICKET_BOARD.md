# チケットボード

最終更新: 2026-05-11
管理者: 秘書

このボードは、部署別運用で発生するタスクを秘書が一本化して管理するための台帳です。
ユーザーへは、チケット全件ではなく「判断が必要なもの」「期限が近いもの」「リスクがあるもの」だけを報告します。

## 1. 運用ルール

### チケット番号

```text
CSG-001
CSG-002
CSG-003
```

`CSG` は Creator Stack Guide の略。
新規チケットは連番で追加する。

### ステータス

| 状態 | 意味 |
|---|---|
| Backlog | まだ着手しない候補 |
| Todo | 着手予定 |
| Doing | 作業中 |
| Review | 検収中、確認中 |
| Waiting | ユーザー操作や外部条件待ち |
| Blocked | 進行不能、明確な障害あり |
| Done | 完了 |

### 優先度

| 優先度 | 意味 |
|---|---|
| P0 | 公開、SEO、収益化に直結。放置すると事故や機会損失がある |
| P1 | 近日対応。検索評価、成約率、信頼性に影響 |
| P2 | 改善、整理、後続効率化 |
| P3 | 余裕があるとき |

### 秘書の報告基準

秘書がユーザーへ報告するもの:

- P0
- `Waiting` でユーザー操作が必要なもの
- `Blocked`
- 公開前にユーザー判断が必要なもの
- Search Console、ASP、成果リンク、費用に関わるもの

秘書が内部更新だけでよいもの:

- Done への移動
- 軽微な説明更新
- 期限や担当部署の整理
- 検収ログの追加

## 4. 完了条件

実装系チケットの完了条件:

- `git diff --check` が通る
- 必要なら `node --check .\scripts\generate-site.mjs` が通る
- `SITE_URL` を指定して生成している
- `example.com`、`undefined`、文字化けが公開成果物にない
- placeholder成果リンクが公開CTAにない

記事/SEO系チケットの完了条件:

- 実測、公式情報、推測が分離されている
- 広告表記が保たれている
- 読者に向かないケースや注意点がある
- 内部リンクが自然につながっている

収益系チケットの完了条件:

- 承認済みリンクだけを使用
- リンク先、報酬条件、cookie、承認状態を記録
- 無料運用の方針から外れていない
