# 低レート時の進め方

残りレートが少ない時は、実装量より判断ミスを減らすことを優先します。

## やる

- 既存ファイルを読む前に `progress/README.md` を見る
- P0だけ進める
- 1回の作業で1テーマに絞る
- 変更後は `node --check` と `git status --short` だけ確認する
- 実測データ、リンク承認、Search Console状態のような事実を優先する

## やらない

- 記事を大量生成する
- デザインを大きく作り直す
- 未承認リンクを貼る
- 有料サービスを契約する
- Search Consoleの一時的な表示だけで大規模修正する

## 迷った時の優先順位

1. 実測レビュー
2. 承認済みアフィリエイトリンク
3. Search Consoleの確認
4. 無料集客テンプレの投稿
5. 新記事追加

## Claude Codeへの短縮指示

```text
progress/README.md を読んで、P0だけ進めて。無料運用を維持し、未実測の断定や未承認リンク掲載はしないで。変更後は生成と構文確認をして、差分を短く報告して。
```
